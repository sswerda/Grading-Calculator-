ROOM 134 GRADING CALCULATOR

Upload ALL FOUR files in this folder to the root of your GitHub repository:

- index.html
- manifest.webmanifest
- icon-192.png
- icon-512.png

Then:
1. GitHub repository → Settings → Pages
2. Build and deployment → Deploy from a branch
3. Branch: main
4. Folder: / (root)
5. Save
6. Open the Pages URL GitHub gives you
7. On iPhone/iPad: Safari → Share → Add to Home Screen
   On Android: Chrome → menu → Add to Home screen / Install app

The custom plant icon should appear on the home screen.
